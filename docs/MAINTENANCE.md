## 驗證工具修整

兩張專輯共用 `scripts/lib/release-validation.cjs`，原本的 `verify-release.cjs` 與 `verify-public.cjs` 路徑保留。

- 依唯一專輯 ID 選取目標，不把全站專輯數量固定為三或四。
- 曲目按 ID 對應帳本，不依陣列順序；下載依 `selectedResult` 選取，不直接使用第一筆下載。
- 核對來源 URL、正式資料 SHA-256、下載副本與正式音檔的 bytes／SHA-256，以及歷史完整解碼證據。
- 本機驗證每次都重新以 FFprobe／FFmpeg 解碼正式音檔至結尾，報告明確標記 `fullDecodePerformedThisRun`。
- 預設只輸出到終端；`--output` 使用獨佔建立，既有輸出拒絕覆寫，即使輸出檔是在參數檢查後才出現也一樣。
- 公開驗證維持 HTTP 檔案／SHA、Range、ZIP 大小與帳本 404 檢查，明確區分瀏覽器播放及聽審未執行。本輪僅以本機隔離 HTTP 測試驗證程式，未向正式網站送出檢查。

沒有 `package.json`，因此 `npm run build`／`npm run lint` 不適用。本輪使用 Node 語法檢查、內建測試工具、實際音檔驗證及前後雜湊比對。
